# Automation-OrangeHRM-Darshan-Rana

Production-grade E2E test automation framework for OrangeHRM built with Cypress (POM). Features dynamic data generation via Faker, custom HTML reporting via Mochawesome, and continuous integration via GitHub Actions.

---

## 🚀 Getting Started

### Prerequisites
* **Node.js** (v18 or higher recommended)

### Installation
1. Clone this repository:
   ```bash
   git clone [https://github.com/Darshan-Rana/Automation-OrangeHRM-Darshan-Rana.git](https://github.com/Darshan-Rana/Automation-OrangeHRM-Darshan-Rana.git)


2. Navigate into the project directory:
  
  cd Automation-OrangeHRM-Darshan-Rana

3. Install the dependencies:

  npm install

4. Running the Tests

To open the Cypress interactive Test Runner UI:
   
   npx cypress open

To run the entire test suite in headless mode and generate the Mochawesome HTML report:
 
   npx cypress run
